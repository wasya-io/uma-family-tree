# プロダクト概要 (uma-family-tree)

JV-Link (JRA-VAN Data Lab.) で取得した競走馬データから血統を **DAG (有向非巡回グラフ)** として構築し、
[3d-force-graph](https://github.com/vasturiano/3d-force-graph) を用いて **3D フォースダイレクテッドグラフ**として可視化する Web ビューア。

## コアコンセプト

- 血統は本来「世代ごとに2倍になる二分木」だが、インブリード (クロス) により同一祖先が複数箇所に現れるため、
  厳密には **DAG** になる。本プロダクトは木ではなく DAG として扱い、同一祖先を **1ノードに集約**する。
  これにより 3D 表示の意味 (クロスの可視化) が生まれる。
- 任意の馬を **中心 (フォーカス)** に据え、**祖先方向・子孫方向の双方向**を辿れる。
- ノードをタップすると、その馬が新しい中心になり再センタリングされる
  (例: ゴルシ中心 → 母父メジロマックイーンをタップ → マックイーン中心)。

## 利用形態

- JV-Link を使ったリアルタイム取得は **行わない**。
- 別マシン (Windows) でダウンロード済みの生データを **事前加工**し、静的な JSON として配信する。
- Svelte アプリは組み立て処理を持たず、**ビューアに徹する** (加工済みデータを読んで描画するだけ)。

## 技術スタック

- ビューア: SvelteKit + 3d-force-graph (Three.js ベース)
- デプロイ: Cloudflare Pages
- データ配信: Cloudflare R2 (独自ドメインのサブドメインでカスタムドメイン配信)
- 加工パイプライン: Python (JV-Link SDK に Python サンプル・構造体定義があるため)
- 構成: モノレポ (加工パイプラインとビューアを同一リポジトリで管理)

## スコープ外 / 非目標

- JV-Link のリアルタイム連携
- フロントエンドでの血統組み立て・重い計算
- 数万ノード規模を一度に描画すること (表示範囲を絞る戦略で回避)
