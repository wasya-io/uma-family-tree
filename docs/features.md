# 機能一覧と使い方ガイド

3D 血統ビューア (viewer) の機能と操作方法。スマホでのタッチ操作を中心に設計している。

本番: <https://uma-family-tree.pages.dev>

---

## 概要

任意の競走馬を中心に据え、血統を **3D の有向非巡回グラフ (DAG)** で可視化する。
祖先方向 (親をさかのぼる) と子孫方向 (子を辿る) の双方向を探索でき、インブリード
(同一祖先が複数箇所に登場) は 1 ノードに集約して表示される。

- 中心 = 原点に固定。祖先 = 上 (+Y)、子孫 = 下 (−Y) に配置。
- ノード色 = 系統 (keitoId)。中心馬はラベルを明滅させて強調。
- リンク = 父方は青の細線、母方は赤の太線 + 流れる粒子 (3D では破線が使えないため色・太さ・粒子で区別)。

## 機能一覧

### 1. 検索
- ヘッダーの検索ボックスに漢字/カナ/欧字を入力するとインクリメンタル検索 (サーバ側, 最大20件)。
- 候補をタップするとその馬を中心に表示。

### 2. 中心の切り替え
- グラフ上のノードをタップ → 詳細パネルが開く → 「この馬を中心にする」で再センタリング。
- URL に `?horse=<id>` が反映され、共有するとその馬を中心に開ける。
- データが無い馬は詳細パネルの「中心にする」が無効化され、404 で操作不能にならないようにしている。

### 3. 祖先表示 (既定)
- 中心馬の祖先を 5 代、子孫を 1 代表示する通常モード。

### 4. 子表示モード
- 左下の「👶 子を見る」トグルで、祖先を消して子孫方向を展開するモードに切替。
- 世代スイッチャー (1代 / 2代 / 3代) で子孫を何代先まで表示するか選べる。
- **代表子孫を優先表示**: 子孫が多い馬では「獲得賞金の多い順」に代表を選抜して表示する
  (重賞級の活躍馬が優先的に出る)。孫以降も各親から賞金上位のみ辿るため、種牡馬でも
  表示が破綻しない。
- **データのある世代までしか操作できない**: 実際に子孫データが存在する世代を判定し、
  それを超える世代ボタンは無効化。孫がいない若い種牡馬では「これ以上の世代のデータは
  ありません」と注記する。

### 5. 代表表示と全表示
- 直仔が多い馬 (40 頭超) は「代表的な子のみ表示中 (全 N 頭)」と注記し、「すべて表示」で
  全子を展開できる (重い)。「代表表示に戻す」で戻せる。

### 6. 詳細パネル
- ノードタップで開く。馬名・欧字・性別・毛色・生年・系統を表示。
- 競走実績がある馬は「◯勝 ・ 獲得賞金 約◯億円」を表示。
- 「🔍 Google」ボタンで、馬名 + 「競走馬」を検索キーワードにした Google 検索を別タブで開く。
- 「この馬を中心にする」で再センタリング。

### 7. カメラ操作
- 1 本指ドラッグで回転、2 本指ピンチでズーム。回転の中心は中心馬 (原点) に一致させている。
- 右下「⟳ 正面に戻す」で初期アングルへ (ズームは変えない)。
- 初回のみ画面下部に操作ガイドを表示 (8 秒で自動的に消える / タップで閉じる)。

### 8. ラベル表示
- 中心から 5 世代までのノードに常時ラベル。中心/選択馬は常に濃く表示。
- ラベルの濃さは世代とカメラ距離で調整 (手前に来たノードは濃く、奥は淡く)。

### 9. データ基準時点と免責事項
- フッターにデータの基準時点を表示 (例: 「本サイトの血統データは 2023年7月31日時点のものです」)。
- 初回は「⚠ 本サイト利用上の注意事項をご確認ください」を表示。タップで免責事項ダイアログを開く。
  一度確認するとガイドは消え、以降はフッターの「免責事項」リンクからいつでも再表示できる。
- 免責の要点: 本サイトは非公式・JRA-VAN 等とは無関係。加工に伴いデータが実際と異なる場合が
  ある。正確性は保証せず、利用は自己責任。

## 操作クイックリファレンス

| 操作 | 動作 |
|---|---|
| ノードをタップ | 詳細パネルを開く (選択) |
| 詳細パネルの「中心にする」 | その馬を中心に再表示 |
| 1 本指ドラッグ | 回転 |
| 2 本指ピンチ | ズーム |
| 左下「子を見る」 | 子表示モードの ON/OFF |
| 世代 1/2/3 | 子孫を何代先まで表示するか |
| 右下「正面に戻す」 | 初期アングルへ |
| フッター「免責事項」 | 免責ダイアログを開く |

## URL パラメータ

| パラメータ | 用途 |
|---|---|
| `?horse=<id>` | 中心馬を指定 (id = `"H" + 繁殖登録番号`)。共有用 |
| `?disclaimer=reset` | 免責の確認状態をリセットして再表示 (開発/再確認用) |
| `?guide=reset` | 操作ガイドをリセットして再表示 (開発/再確認用) |

## 設計上の判断 (なぜそうなっているか)

- **スマホ中心設計**: PC マウス前提のホバーや標準ナビ表示 (showNavInfo) は使わず、タッチ操作と
  常時ラベル + 詳細パネルで構成。
- **大量の子ノードへの配慮**: 一律に全子を出すと密集して見づらい (集合体感)。代表子孫の優先 +
  各世代の賞金上位絞り込み + 「すべて表示」トグルで、破綻を避けつつ深掘りも可能にしている。
- **「強さ」の指標**: 保有データ (UM) に重賞勝ちフラグは無いため、獲得賞金・勝利数を代表子孫の
  優先指標に採用 (詳細は [`data-model.md`](./data-model.md) §3)。
- **データの正確性**: 加工を伴うため誤り・欠落がありうる。免責事項とデータ基準時点を明示している。

機能の裏側 (スキーマ・探索アルゴリズム) は [`data-model.md`](./data-model.md)、
デプロイ手順は [`deploy.md`](./deploy.md) を参照。
